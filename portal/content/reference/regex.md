# Регулярные выражения — шпаргалка
<!-- tags: regex, text, development, search -->

Базовые конструкции и практические шаблоны для редактора и командной строки.

## Конструкции

| Шаблон | Значение |
| --- | --- |
| `^` / `$` | начало / конец строки |
| `.` | любой символ, кроме перевода строки |
| `*` / `+` / `?` | 0+, 1+, 0 или 1 повтор |
| `{2,5}` | от двух до пяти повторов |
| `[a-z]` | символ из диапазона |
| `[^0-9]` | любой символ, кроме цифры |
| `(...)` | группа с захватом |
| `(?:...)` | группа без захвата |
| `(?<name>...)` | именованная группа, если движок поддерживает |
| `\b` | граница слова |

## Частые флаги

| Флаг | Значение |
| --- | --- |
| `i` | без учёта регистра |
| `m` | `^` и `$` работают для каждой строки |
| `s` | точка совпадает и с переводом строки |
| `g` | найти все совпадения |
| `u` | Unicode-семантика |

## Практические примеры

```text
# пустая или пробельная строка
^\s*$

# целое число со знаком
^[+-]?\d+$

# простой slug
^[a-z0-9]+(?:-[a-z0-9]+)*$

# ISO-дата YYYY-MM-DD
^\d{4}-(?:0[1-9]|1[0-2])-(?:0[1-9]|[12]\d|3[01])$
```

Не используйте регулярное выражение как полноценный валидатор сложных форматов вроде URL или email — после грубой проверки всё равно нужен профильный парсер.

> Проверяйте выражения на длинных несовпадающих строках: вложенные квантификаторы могут резко замедлять обработку.
